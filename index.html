처음 한 번만

컴퓨터 한 대에 딱 한 번 하는 준비입니다.

  1. 1

    파일 내려받고 내 PC에 저장

    위의 내려받기 버튼을 누르고, 저장합니다.

    팀 이름을 붙여 두면 나중에 헷갈리지 않습니다. 예: 토요일시간표_생성기_6팀.xlsx

  2. 2

    파일을 열고 편집 사용 누르기

    인터넷에서 받은 파일이라 위에 노란 띠로 편집 사용 또는 콘텐츠 사용 버튼이 뜹니다. 눌러 주세요. 안 누르면 새로 고침이 안 됩니다.

  3. 3

    개인 정보 수준 끄기 — 이걸 빼먹으면 오류가 납니다

    공유폴더의 파일과 이 파일 안의 표를 같이 쓰기 때문에, 엑셀이 보안을 이유로 막습니다. 미리 꺼 둡니다.

    데이터 탭 → 데이터 가져오기 → 쿼리 옵션

    왼쪽에서 전역 → 개인 정보 → ◉ 개인 정보 수준 설정을 항상 무시

    이어서 현재 통합 문서 → 개인 정보 → ☑ 개인 정보 수준을 무시하고 잠재적으로 성능 향상 → 확인

    컴퓨터마다 다시 해야 합니다 이 설정은 파일이 아니라 엑셀 프로그램에 저장됩니다. 다른 컴퓨터에서 열면 그 컴퓨터에서 한 번 더 해 주세요. 병원 내부 파일끼리만 합치는 것이라 보안상 문제 없습니다.
  4. 4

    마스터 시트에 우리 팀 환자 명단 채우기

    배포판의 마스터 시트는 비어 있습니다. 팀마다 환자가 다르기 때문입니다.

    EMR에서 담당 병동 입원환자 목록을 내려받아, 이름과 병실 두 열만 복사해 붙여넣습니다.

    A열 (이름) B열 (병실)
    홍길동 1001
    김철수B 1002

    이름은 시간표에 적히는 그대로 넣어 주세요. 동명이인 구분자(뒤에 붙는 B, C 같은 알파벳)도 빠뜨리면 안 됩니다.

    병실이 왜 필요한가요 PT·OT 원본 어디에도 병실 번호가 없습니다. 마스터 시트가 유일한 출처라, 여기 없는 환자는 병실이 신환 으로 표시됩니다.
  5. 5

    설정 시트에 파일 경로 넣기

    설정 시트의 노란 칸 두 개에 이번 주 PT·OT 파일의 전체 경로를 넣습니다.

    직접 타이핑하지 마세요. 파일명에 괄호와 쉼표가 있어서 한 글자만 달라도 못 찾습니다.

    탐색기에서 파일을 Shift + 마우스 오른쪽 클릭 → 경로로 복사 → 설정 시트 칸에 Ctrl+V

    붙여넣으면 앞뒤에 큰따옴표가 같이 옵니다. 그냥 두세요. 프로그램이 알아서 떼어냅니다.

    Shift 를 안 누르면 오른쪽 클릭 메뉴에 경로로 복사 가 안 보입니다. Shift 를 누른 채로 오른쪽 클릭해야 나옵니다.
  6. 6

    첫 실행

    데이터 탭 → 모두 새로 고침

    처음에는 자격 증명 창이 뜰 수 있습니다. Windows 자격 증명 → 현재 자격 증명 사용 → 연결 을 누르세요. 공유폴더에 처음 접근할 때 한 번만 물어봅니다.

    출력 시트에 이름·병실·시간대 6칸이 채워지면 성공입니다.

    마지막으로 잘 되는 걸 확인했으면 파일을 복사해 백업본을 하나 만들어 두세요. 나중에 잘못 건드려도 되돌릴 수 있습니다.

매주 하는 일

준비가 끝난 뒤에는 이것만 반복합니다.

  1. 1

    이번 주 파일 경로로 바꾸기

    설정 시트의 PT파일·OT파일 경로를 이번 주 파일로 교체합니다. (Shift+오른쪽 클릭 → 경로로 복사)

    같은 날짜에 시간표가 여러 개 올라오는 경우가 있어서, 어느 파일을 썼는지 확실하도록 경로를 직접 지정하는 방식입니다.

  2. 2

    새로 고침

    데이터 탭 → 모두 새로 고침

    몇 초면 끝납니다. 오른쪽 아래에 회전 표시가 사라지면 완료입니다.

  3. 3

    신환 채우기

    출력 시트를 맨 아래까지 내려서 병실 칸이 신환 인 행을 봅니다.

    그 환자의 호수를 찾아 마스터 시트 맨 아래 빈 줄에 이름과 병실을 입력합니다.

    퇴원 환자를 지울 때는 행 번호를 오른쪽 클릭 → 삭제 로 행째 지우세요. Delete 로 글자만 지우면 빈 줄이 쌓입니다.

  4. 4

    다시 새로 고침

    마스터를 고쳤으면 모두 새로 고침을 한 번 더. 신환이 병실 순서대로 제자리에 들어갑니다.

    순서가 중요합니다 마스터 정리를 ★★★ 에 붙여넣기 전에 끝내세요. 붙여넣고 나서 고치면 다시 붙여넣어야 합니다.
  5. 5

    ★★★ 파일에 옮기기

    ★★★ 파일을 열고, 늘 하던 대로 지난주 시트를 복사해 이번 주 시트를 만듭니다.

    복사: 생성기 출력 표 안의 아무 칸을 클릭하고 Ctrl+A → Ctrl+C
    표의 데이터 영역만 정확히 잡힙니다. 행 수가 매주 달라져도 신경 쓸 필요 없습니다.

    붙여넣기: ★★★ 새 시트의 A2 칸을 클릭하고 Ctrl+Alt+V → V → Enter

    꼭 "값"으로 붙여넣기 그냥 Ctrl+V 로 붙이면 서식과 연결이 같이 넘어가서 ★★★ 파일이 이상해질 수 있습니다. 마우스로 하려면 오른쪽 클릭 → 붙여넣기 옵션 의 값 아이콘(123 모양)입니다.
  6. 6

    확인하고 인쇄

    ★★★ 오른쪽 카드가 자동으로 채워집니다. 몇 명 눈으로 확인하고 인쇄하면 끝입니다.

    자잘한 수정은 ★★★ 쪽에서 직접 하세요. 생성기 출력 시트에서 고치면 다음 새로 고침 때 사라집니다.

병실 칸에 신환

마스터 시트에 없는 이름이라는 뜻입니다. 세 가지 경우가 있습니다.

① 진짜 새 환자 → 호수를 찾아 마스터에 추가
② 이름 표기가 다름 (시간표엔 김명순, 마스터엔 김명순B) → 마스터 쪽 철자를 시간표와 맞추거나, 별칭 시트에 원본표기 / 실제이름 한 줄 추가
③ 퇴원했는데 시간표에 남음 → 원본 확인

칸에 확인필요

이름은 읽었는데 무슨 치료인지 표기가 없다는 뜻입니다. 추측해서 틀린 값을 넣지 않고 눈에 띄게 표시하는 것입니다.

원본에서 그 이름을 찾아보고, ★★★ 에 붙여넣은 뒤 그 칸만 직접 채우세요. 자주 나온다면 새로운 표기법이 생긴 것이니 관리자에게 알려 주세요.

한 칸에 치료가 두 개 — 운동치료 / 작업치료

같은 환자가 같은 시간에 두 곳에 잡혀 있다는 뜻입니다. 프로그램 오류가 아니라 원본을 확인해 봐야 할 신호입니다.

시간대가 예상과 다름

시간대는 원본 파일에서 자동으로 읽습니다. 팀마다 다릅니다. 이상하면 설정 시트의 경로가 다른 팀 파일을 가리키고 있는지 확인하세요.

별칭 시트

시간표의 이름과 마스터의 이름이 같은 사람인데 글자가 다를 때, 둘을 이어 주는 표입니다. 평소에는 비어 있어도 됩니다.

먼저 확인하세요 — 대부분은 별칭이 필요 없습니다 /홍길동 C 처럼 공백만 다른 경우, 이름 앞뒤의 / G N S VT 같은 기호, 괄호와 그 안의 내용((OS) (1-3))은 프로그램이 알아서 떼고 찾습니다. 별칭에 적지 않아도 됩니다.

이럴 때 씁니다

글자 자체가 빠지거나 다른 경우입니다. 시간표에는 김길동 이라고만 적혀 있는데 마스터에는 동명이인 구분자가 붙은 김길동B 로 들어 있거나, 외국인 환자 이름이 시간표에서는 짧게 적히는 경우입니다.

어느 칸에 무엇을 적나

A열 — 원본표기 B열 — 실제이름
김길동 김길동B
이길동 이길동C
DONG HONG DONG
HDONG HONG DONG

A열은 시간표에 적힌 그대로(치료 기호는 뗀 이름만), B열은 마스터 A열에 있는 이름과 한 글자도 다르지 않게 적습니다.

같은 사람이 시간표마다 다르게 적힌다면 표기마다 한 줄씩 추가하세요. 위의 DONG · HDONG 처럼 두 줄이 됩니다.

이런 건 하지 마세요 방향을 바꿔 적으면 찾지 못합니다. 왼쪽이 시간표, 오른쪽이 마스터입니다.
B열에 마스터에 없는 이름을 적으면 그대로 신환 으로 남습니다. 마스터부터 확인하세요.
진짜 다른 사람을 이어 붙이면 안 됩니다. 동명이인이라면 별칭이 아니라 마스터와 시간표 양쪽의 구분자(B C)를 맞추는 쪽이 맞습니다.

별칭을 고친 뒤에는 데이터 탭 → 모두 새로 고침 을 한 번 더 눌러야 반영됩니다.

문제 해결

위에서부터 확인해 보세요.

"데이터 원본에 직접 액세스할 수 없습니다" / Formula.Firewall

처음 한 번만 3단계(개인 정보 수준 끄기)를 안 했거나, 다른 컴퓨터에서 열어서 그 PC에 설정이 안 된 경우입니다. 전역과 현재 통합 문서 양쪽 다 해 주세요.

"값 null을(를) Logical 형식으로 변환할 수 없습니다"

원본에서 데이터를 하나도 못 찾았다는 뜻입니다. 설정 시트의 경로를 그대로 복사해 탐색기 주소창에 붙여넣고 Enter 를 쳐 보세요. 파일이 열리면 경로는 정상이고, 안 열리면 경로가 틀린 것입니다.

출력 시트가 비어 있음

경로가 틀렸거나 아직 새로 고침을 안 한 경우입니다. 데이터 → 쿼리 및 연결 을 눌러 오른쪽 창에서 출력 아래에 "○개의 행이 로드되었습니다" 가 뜨는지 확인하세요.

쿼리 목록에 노란 ⚠ 표시가 남아 있음

오류가 아닙니다. 화면에 내보내지 않는 중간 계산이라 미리보기를 저장하지 않는다는 표시입니다. 진짜 오류면 빨간 글씨로 오류 이름이 같이 나옵니다.

새로 고침이 안 됨 / 파일이 잠김

원본 PT·OT 파일을 다른 사람이 편집 중이면 읽기가 막힐 수 있습니다. 잠시 뒤 다시 시도하거나, 파일을 복사해 두고 그 복사본 경로를 쓰세요.

★★★ 파일이 이상해졌다

생성기는 ★★★ 를 건드리지 않으므로 붙여넣기 과정의 문제입니다. Ctrl+Z 로 되돌리고, 저장하지 않은 채 닫았다 다시 열면 원래대로 돌아옵니다.

그래도 안 될 때

오류 창을 화면 캡처해서 관리자에게 보내 주세요. 어느 팀 파일로, 어느 단계에서 났는지 같이 적어 주면 빠릅니다.

원본을 읽는 규칙

궁금할 때 참고하세요. 평소에는 몰라도 됩니다.
